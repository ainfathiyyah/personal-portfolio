# Personal Portfolio Website

## Project Description

This project is a personal portfolio website developed to showcase my academic achievements, university activities, projects, technical skills, and creative works throughout my studies.

The website contains multiple sections including Home, About, Blog, Achievements, Projects, Activities, and Contact.

---

## Features

- Responsive portfolio website
- Navigation bar
- About Me section
- Education background
- Achievement slider
- Activities and programs gallery
- Project showcase section
- Read More functionality
- Contact information

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code

---

## Project Pages

### Home Page
Introduction and portfolio overview.

### About Page
Personal information, education background, and skills.

### Blog Page
Achievements, activities, and project showcase.

### Contact Page
Contact details and communication information.
