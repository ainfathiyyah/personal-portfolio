My Projects

A collection of projects and practical work completed throughout my studies.

Virtual Human Anatomy Via Virtual Reality

This Final Year Project was developed using Unity and Virtual Reality (VR) technology to create an interactive learning environment for human anatomy.

Users can explore 3D models of bones, muscles, and organs while learning their names, locations, and functions in a more engaging way.

The system also includes a quiz feature that allows users to test their knowledge after learning. In addition, users can move around and explore the virtual environment, creating a more immersive learning experience.

3D Animation

This project was developed using Blender as part of a final assessment to create a short 3D animation.

The project involved creating 3D models, designing scenes, and animating a character using various animation techniques. Through this project, I gained practical experience in 3D modelling, character creation, and animation development.

The animation tells a simple story about cleaning a living room. It begins with a messy environment and shows the process of organizing and cleaning the space until it becomes neat and tidy.

3D Modelling

This project was developed using Autodesk Maya as part of a final assessment. The project focused on creating a 3D workshop environment by applying various modelling techniques.

The project involved designing and modelling different workshop tools and objects, including hammers, saws, nails, wood materials, and other equipment commonly found in a workshop.

In addition, a complete workshop scene was created by arranging the 3D objects within the environment. Through this project, I gained practical experience in 3D modelling, object creation, scene composition, and environment design using Maya.

Photography

This project was completed as part of a photography assignment using a Canon camera. The project focused on applying photography techniques to capture high-quality product images.

Several products were selected for the photoshoot, including lip matte products and hijabs. Different angles, lighting setups, and compositions were used to create attractive and professional-looking photographs.

Through this project, I gained practical experience in product photography, camera handling, lighting techniques, and photo composition while producing images suitable for promotional and marketing purposes.

Videography

This project was completed as part of a final assessment focusing on environmental awareness. The video highlighted the importance of protecting the environment and encouraged positive actions towards sustainability.

Another videography project involved producing a short story video using only an iPhone 14 Pro Max. The project focused on storytelling, camera angles, shot composition, and creative video production techniques.

All footage was edited using CapCut Pro, where transitions, visual effects, background music, and color adjustments were applied to create engaging and professional-quality videos.
